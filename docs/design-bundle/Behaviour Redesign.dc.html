3cThe interaction system
[ SYSTEM ]Motion, states, and when not to

One rule holds the whole thing together: nothing translates. No element ever slides, rises, or drifts. Motion is only a change of colour, border or height — which is why it is cheap, why it survives reduced-motion, and why it can never be confused with decoration. Opacity is never used on text, at any state.

MOTION SCALE — THREE DURATIONS, NO OTHERS
TokenTimeUsed for, and only for
state120msPointer is on a control — button, chip, link, row.
address160msAn instrument becomes the one being read, or stops being it. Colour and border only.
disclose220msThe reader opened something — limits, correction detail, mobile nav.

Easing: cubic-bezier(.2, 0, 0, 1) for all three. One curve. Nothing bounces, nothing overshoots — an instrument that overshoots is a broken instrument.

WHEN MOTION IS USED AT ALL
YES — THREE CASES
Something is being addressed.
Something was opened.
A value changed meaning.
NEVER
On arrival. On scroll, as reveal.
Between pages.
Continuously, ever.

The one continuous element is the 1px progress hairline under the header. It is a position readout, not an animation — it has no transition and it stays on under reduced motion.

Focus is one treatment site-wide: 2px accent outline, 2px offset, matching radius, never removed. Focus also forces the reading state — a keyboard user addresses instruments exactly as a pointer does.

THE RULE THAT KEEPS THIS THROUGH THE GATE
Receding is never opacity on text. A receded instrument sets its title in the muted token at full opacity — #5c6068 on #fafafb, 5.4:1 — keeps its headline metric at full foreground, and gives up its frame, screenshot and elevation instead. Automated contrast is graded on the page as loaded, so a state that only becomes legible under reduced-motion still fails. Type minimum for any label carrying meaning: 12px mono. Below that it is decoration and should not exist.
PREFERS-REDUCED-MOTION
All three durations go to 0. The reading line is not drawn and nothing changes state on scroll — every instrument renders framed and complete, in document order, so the page becomes a plain vertical rack of readings. Disclosures render open. Nothing is only available through a transition, so nobody loses content; they lose emphasis. That same state is the fallback for any browser without scroll-driven animation, which means there is no broken path to maintain — just two valid ones.
